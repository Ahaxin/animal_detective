# Animal Detective · 动物侦探

当前开放两案：阳光花园「太阳蓝宝石失窃案」和丰收果园「失踪的金苹果」。复古配色的立体微缩花园，真实 WebGL 3D 模型与实时阴影。侦探可自由走动，支持完全离线运行。

手机线上测试：https://animal-detective-sunshine-garden.bradin.chatgpt.site （保留现有公开访问设置）。初次联网加载完成后支持缓存离线重开；可通过手机浏览器“添加到主屏幕”使用独立窗口。存档按设备、浏览器与访问地址分别保存，不会自动同步电脑进度。

现已改成单一游戏主画面：花园占满窗口，资源、目标、对话与操作都在游戏内显示，没有网页页头、页脚、常驻侧栏或页面滚动。手记与背包通过工具栏在画面内打开。

## 开始游玩

双击 `启动游戏.cmd`，或用 Chrome / Edge 打开 `index.html`，无需安装依赖。

也可以运行 `npm start`，访问 http://127.0.0.1:5173 。两种打开方式的浏览器存档彼此独立，建议固定使用同一种方式。

## 操作

- 点击地面寻路，也可用方向键 / WASD / 左下角摇杆自由移动；展台、花坛、树木和边界有碰撞。
- 点击动物或名字交谈；完整听完后，证词会进入手记。
- 首次进入免费永久领取放大镜，直接点击橡果、羽毛或地洞调查，场景不显示提示图标。
- 手记可以重新查看已发现的线索和已听过的证词。
- 底部工具栏：手记、背包、指认、提示；较矮的横屏窗口使用右侧竖排工具栏。
- J 打开 / 收起手记，I 打开背包，Esc 关闭可关闭的面板。读手记时暂停移动。
- 收集三条线索、三份证词后，选择嫌疑人并出示证物。
- 提示消耗 1 星。指认错误扣除最多 2 星并重开案件；星星不足也可继续。
- F / 右上角按钮切换全屏。右上角切换中文和荷兰语，可选开启环境音。
- 本地自动保存；相同浏览器和打开方式可继续调查。

## 开发验证

`node --check game.js` 检查脚本；`npm test` 运行本机配置的 Playwright 全流程测试（需先启动本地服务器）。`node tests/screen-layout.test.mjs` 验证六种窗口与旧存档，`node tests/offline.test.mjs` 验证双击离线启动。最新截图与结果在 `output/single-screen/`。开发测试使用本机已有 Chrome 和 Codex 附带 Playwright，游戏发布文件不依赖这些工具。

本次按用户指定的 GameStudio skill 进行 UI/UX 与运行验证。检查记录见 `UI_AUDIT.md`，项目交接见 `CODEX_HANDOFF.md`。

发布入口：`publish/animal-detective/`，仅包含经过压缩的运行文件。`scripts/build-mobile.cjs` 将根目录源码和资源打包到其 `dist/`；更新资源前需变更 `sw.js` 的缓存版本，避免旧缓存。移动端触控、缓存离线重开与存档检查：`node tests/mobile-release.test.mjs`。

美术资产、提示词和生成方式见 `assets/ART-NOTES.md`。

## 3D 开发

`npm ci` 安装锁定依赖，`npm run build:3d` 将 world3d.js 与 Three.js 打包到 world3d.bundle.js。运行时没有 CDN 请求。Three.js 0.180.0（MIT，见 THREE-LICENSE.txt）。固定俯视透视镜头；模型为程序化低多边形风格。

验证：`node tests/3d-movement.test.mjs` 检查真实触摸摇杆、释放停止、碰撞、暂停与存档；原有完整第一关、六种布局和离线测试继续适用。物理手机帧率和发热尚未测量。

2026-10-26 更新：开局可指认；仅已发现的物证可用于结案。背景音乐首次点击开始后播放，♪ 按钮静音并记住偏好。全屏按钮在支持的浏览器中进入全屏；iPhone 可通过 Safari 分享 → 添加到主屏幕获得独立窗口。

## 第二关：丰收果园

从案件档案进入，或在第一关结案后选择第二关。背包 / Tas 的红色感叹号表示需要皮尺：永久兑换 1 爱心，或本案租赁 5 金币；租赁包含误判重试、刷新和暂时切换案件，主动重玩后到期。永久皮尺不会重复扣费。资源不足可以先回第一关赚奖励。

直接点击脚印、树上的香蕉皮 / 断枝、东入口漆桶取证；组合选中赤脚印和高处断枝后指认猴子。奖励 3 星、1 爱心、12 金币，每次调查结案发放一次。两关调查进度分别保存，角色、资源、永久道具共用，旧 v1 存档自动保留。

剧情把猴子的说法统一为“昨晚到今天”；红漆颜色不被当作屋顶油漆的唯一来源，脚印和断枝组合后通过脚底核对与供认完成推理。

新增检查：`node tests/orchard.test.mjs`；`node tests/orchard-layout.test.mjs`。
